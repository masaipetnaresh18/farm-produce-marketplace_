# 🌾 Farm Produce Marketplace

A web-based marketplace that connects farmers directly with buyers.

## Features

- Farmer can list agricultural products
- Product quantity and price management
- Buyers can browse available products
- Buyers can place direct orders
- Automatic quantity update after ordering
- Order tracking
- SQLite database
- Responsive web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
